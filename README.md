# Paperclip Agency Workspace

This repository is the top-level workspace for Paperclip code, agency planning,
and client-specific operating context.

## Layout

- `local-paperclip/` contains the Paperclip application source.
- `.planning/agency-core/` contains shared agency templates and operating state.
- `.planning/company/astrogen/` contains Astrogen-specific planning state.
- `.planning/company/diskinternals/` contains DiskInternals-specific planning state.
- `ops/` contains deployment and operations examples.

Runtime artifacts, caches, local screenshots, and plaintext secrets are
intentionally excluded from Git.
