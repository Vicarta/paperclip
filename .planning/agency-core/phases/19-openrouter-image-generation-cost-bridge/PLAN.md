# Phase 19: OpenRouter Image Generation Cost Bridge

## Objective

Move governed image generation out of ad hoc agent shell HTTP calls and into a reusable Paperclip plugin/adapter path that writes provider spend to canonical `cost_events`.

## Problem

Astrogen cover images are generated by a Codex-local image runtime agent that calls OpenRouter directly from `/astrogen/bin/execute-seo-blog-image-provider-request`. OpenRouter dashboard shows real paid spend for the Paperclip API key, but Paperclip `cost_events` only records the reasoning agent run, not the image-provider call. This makes company cost totals and efficiency KPIs undercount Nano Banana 2 / OpenRouter image generation.

## Scope

1. Add a reusable OpenRouter image generation agent-tools plugin.
2. Register a tool that accepts a governed image prompt/request and calls OpenRouter server-side with a secret-backed API key.
3. Extract provider cost from OpenRouter response when present and write a `metered_api` `cost_events` row.
4. Support configured estimated fallback cost when OpenRouter does not return request-level cost.
5. Return generated image data/metadata in a form the runtime agent can write to its existing Stage 65 bundle.
6. Update Astrogen image-generation contracts so agents use the plugin tool as the primary path and keep direct shell dispatch only as a temporary diagnostic fallback.
7. Verify locally and on production that a tool call creates a cost ledger event for model `google/gemini-3.1-flash-image`.

## Non-Goals

- Do not redesign the article image creative contract.
- Do not change the SEO Blog Image Runtime Executor reasoning model.
- Do not store OpenRouter secrets in prompts, docs, frontend code, or repo files.
- Do not backfill historical OpenRouter spend from the dashboard in this phase.

## Implementation Plan

1. Create `@paperclipai/plugin-openrouter-image-agent-tools`.
2. Add instance settings:
   - `openrouterApiKeySecretRef`;
   - `openrouterBaseUrl` default `https://openrouter.ai/api/v1`;
   - `defaultModel` default `google/gemini-3.1-flash-image`;
   - `costAccountingMode`: `provider_reported`, `estimated_per_image`, or `disabled`;
   - `estimatedImageCostUsd` for provider responses without cost fields.
3. Add tool `generate-image` with parameters:
   - `prompt` required;
   - `model`, `aspectRatio`, `imageSize`, `outputFormat`, `metadata`, `seed`, `temperature`, `topP` optional;
   - `returnImageData` default true for agent bundle writing.
4. Implement OpenRouter client:
   - call `/chat/completions` with `modalities: ["image", "text"]`;
   - include `image_config` and metadata;
   - extract `choices[].message.images[].image_url.url` data URLs;
   - sanitize provider response before returning;
   - extract `usage.cost`, `usage.total_cost`, `cost`, or `total_cost`.
5. Cost bridge:
   - write `cost_events` with provider/biller `openrouter`, billing type `metered_api`, model equal effective image model;
   - if exact provider cost is present, use it;
   - otherwise, when configured, use estimated cost and accumulate fractional cents in plugin state.
6. Tests:
   - tool registers and calls mocked OpenRouter;
   - provider-reported cost writes one cost event;
   - estimated sub-cent cost accumulates before writing a cent;
   - failed provider call writes no cost;
   - no raw base64 image data leaks into sanitized response body.
7. Astrogen contract update:
   - Stage 65 image runtime executor must call `paperclip.openrouter-image-agent-tools:generate-image` as the default generation path;
   - the helper script may remain for bundle assembly/validation and emergency diagnostics, but not as the primary paid provider path.
8. Production rollout:
   - build plugin and app image;
   - deploy Paperclip app only;
   - install/enable plugin if not already installed;
   - configure Astrogen plugin secret ref to existing OpenRouter secret;
   - smoke a controlled tool call and confirm `cost_events` row exists.

## Acceptance Criteria

- OpenRouter image generation can be invoked through a Paperclip plugin tool.
- Successful tool call returns at least one generated image data URL/asset metadata.
- Successful tool call writes a `cost_events` row for `google/gemini-3.1-flash-image` when provider-reported or estimated cost is available.
- Failed provider call does not write cost.
- Astrogen image runtime contract names the plugin tool as primary and direct shell dispatch as fallback-only.
- Production smoke proves Paperclip ledger now includes OpenRouter image model cost events.
