# Agency Core Planning

Use this scope for reusable agency-level assets only:

- shared Paperclip agent templates and naming conventions;
- reusable contracts for SEO, MKT, ADS, SOC, OPS, CEO, CMO, and CTO roles;
- shared plugin architecture and deployment notes;
- cross-client governance, budget, and isolation rules;
- reusable onboarding checklists for new client companies.

## Current Reusable Contracts

- `agents/MKT_GROWTH_STRATEGY_ARCHITECT.md` - MKT specialist for growth strategy options after product discovery.
- `processes/15_STRATEGIC_OPPORTUNITY_BRIEF.md` - Stage 15 process between Product Discovery and downstream execution.
- `processes/SEMANTIC_CORE_MCP_AGENT_INSTRUCTIONS.md` - Semantic Core MCP operating contract, including competitor SERP recall and content-parsing expansion rules.
- `processes/SEO_PERFORMANCE_LOOP.md` - shared multi-company SEO performance loop for sitemap discovery, GSC query accumulation, semantic-core growth, rank tracking policy, new-page opportunities, and product-launch SEO packages.

- `phases/02-seo-ops-postgres-schema/PLAN.md` - implemented `seo_ops` Postgres schema for durable SEO Performance Loop state.
- `phases/02-seo-ops-postgres-schema/SUMMARY.md` - Phase 2 implementation summary and verification record.
- `phases/04-seo-ops-operational-memory-decision-windows/PLAN.md` - planned refinement for page-level SERP targets, decision windows, action history, bounded GSC/GA4 digests, and semantic-core review artifact handoff.
