# Agency Core Planning

Use this scope for reusable agency-level assets only:

- shared Paperclip agent templates and naming conventions;
- reusable contracts for SEO, MKT, ADS, SOC, OPS, CEO, CMO, and CTO roles;
- shared plugin architecture and deployment notes;
- cross-client governance, budget, and isolation rules;
- reusable onboarding checklists for new client companies.

Do not put Astrogen- or DiskInternals-specific execution state here.
