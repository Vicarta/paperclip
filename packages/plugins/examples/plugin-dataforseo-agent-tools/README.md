# DataForSEO Agent Tools

Server-side Paperclip plugin for retrieving keyword demand from DataForSEO.

Current scope:
- keyword demand via `keywords_data/google_ads/search_volume/live`
- secret-backed `API login` and `API password`
- provider-cost attribution from DataForSEO response cost

The plugin is intended for SEO research and prioritization workflows where agents need search-volume-backed keyword evidence rather than SERP shape alone.
